Thank you for reading about this game! Made during Lab 2
Title: Zombie chase. (you are not chasing.)
Desc: You play as steve trying to get as many beef's as possible with out getting caught by zombies.

File descriptions:

controller.py: THis one was not edited but controls the gameplay loops, turn updates and inputs.

boardDisplay.py: Not edited, and controls all the games graphics, drawing the board, score display, and game over text.

cell.py: Not edited and represents a single cell (every cell) on the board, and that cell's type.

preferences.py: It was edited to point to the proper image paths for customization. But this also holds many important valuses, such as board size, colors, timings for gameplay and the aforementioned image paths.

gameData.py: It was edited to add on many of the definitions to allow the game to work properly. And it stores the game data such as board state, enemies, food and the player location, along with logic to allow the game to run.

images folder: It was edited to be pictures of minecraft relatedness. For fun. :3

To run this game, firstly: be in a virtual environment with pygame-ce installed. For vs code, 'py -m pip install pygame-ce'

then with the game file, rune 'controller'py"

and then use arrow keys or ijkl, to move up down left and right to collect beef and avoid zombies!
